Gestalt Python SDK
==================

Use :mod:`gestalt` to build executable Gestalt providers with Python models,
decorators, runtime providers, host-service clients, and telemetry helpers.

The package is published as ``gestalt-sdk`` and imported as ``gestalt`` in
provider projects.

The reference documents everything the package exports: the root
:mod:`gestalt` page covers the flat import surface, and each public submodule
page covers one service's native types and client. Runtime transport
internals are private and excluded.
