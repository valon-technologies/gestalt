# UI (Deprecated)

<Callout type="warning">
  `providers.ui`, `kind: ui`, and `spec.ui` are deprecated. New applications
  ship frontend and backend in one `kind: app` package. Configure
  `apps.<name>.static` in deployment config instead of mounting a separate UI
  provider. See [Applications](/applications) for the unified model.
</Callout>

The standalone UI provider model mounted static bundles through `providers.ui`
or `apps.<name>.ui`. Gestalt still accepts those shapes during the transitional
period, but new work should use app-level static assets.

## What replaced it

| Deprecated | Replacement |
| --- | --- |
| Sibling `ui/manifest.yaml` (`kind: ui`) | Frontend source in the same app repo; `build` writes to `GESTALT_BUILD_STATIC` |
| `spec.ui.path` in app manifest | Optional static output from `build`; packaged as `static/` in release archives |
| `apps.<name>.ui.path` / `ui.bundle` | `apps.<name>.static.mount` |
| `providers.ui.<name>` | `apps.<name>.static` on the owning app |
| `spec.routes[].allowedRoles` | App-level authorization via `authorization.models.<m>.resourceTypes.<app>.defaultRole` and relationships |
| UI manifest `dev:` block | App manifest `run:` commands with `readyTimeout` for local dev proxy |

## Before and after

**Before (deprecated):**

```yaml
apps:
  roadmap_review:
    source: ./roadmap-review/app/manifest.yaml
    ui:
      path: /roadmap
    authorizationPolicy: roadmap_review
```

```yaml
kind: app
spec:
  ui:
    path: ../ui/manifest.yaml
```

**After (unified):**

```yaml
apps:
  roadmap_review:
    source: ./roadmap-review/manifest.yaml
    static:
      mount: /roadmap
    authorizationPolicy: roadmap_review
```

```yaml
kind: app
source: github.com/acme/apps/roadmap-review
version: 1.0.0
install:
  - [npm, ci]
build:
  - [npm, run, build]
run:
  - command: [npm, run, dev]
    readyTimeout: 120s
spec:
  connections:
    default:
      auth:
        type: none
```
