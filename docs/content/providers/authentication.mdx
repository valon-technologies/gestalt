
# Authentication

The authentication provider has been renamed to **[Identity](/providers/identity)**.

The `providers.authentication` and `server.providers.authentication` config keys
remain accepted as legacy spellings for `providers.identity` and
`server.providers.identity`. The `AuthenticationProvider` SDK types remain as
deprecated aliases for `IdentityProvider`.

See the [Identity provider documentation](/providers/identity) for the current
SDK contract, configuration, and examples.
