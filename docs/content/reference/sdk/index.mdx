# SDKs

Gestalt provides SDKs to allow expressing [plugin](/providers/plugins)
providers programmatically instead of declaratively, or to build custom
[providers](/providers) that do not yet exist.

## Native input coverage

The SDK examples use native input helpers for manager requests where those
helpers exist. That includes agent-manager messages and tool refs, workflow
events, workflow signals, and bound workflow targets in Go, Python, and Rust.
TypeScript workflow examples use root helper functions such as
`workflowEvent`, `workflowSignal`, and `boundWorkflowTarget` when a manager
field would otherwise expose a transport-specific shape.

Manager responses now return native SDK objects as well. Examples should read
plain fields such as `session.ID`, `turn.id`, `run.id`, or `event.type` rather
than generated protocol accessors.
